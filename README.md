# Freetown Flavours

## Project Overview

Freetown Flavours lets customers discover the restaurant, browse the menu and services, learn about the story behind the food, and get in touch, from a phone, tablet or desktop. The visual style is clean and modern: a white background with a blue accent colour, inspired by a Twitter-style interface.

The site is a direct implementation of the Assignment 1 design (hand-drawn wireframes, Figma prototype and project proposal).

## Features

- Responsive layout for mobile, tablet and desktop
- Consistent navigation bar and footer across all pages
- Menu and services section showcasing Sierra Leonean dishes
- Contact page with a contact form and restaurant details
- Clean white and blue design system with consistent typography and spacing
- Semantic HTML and organised, commented CSS

## Responsive Design

The site uses a mobile-first approach with these breakpoints:

| Device | Width |
|--------|-------|
| Mobile | up to 600px |
| Tablet | 601px to 1024px |
| Desktop | 1025px and above |

On mobile, the navigation collapses into a menu button and content stacks vertically. On larger screens, content moves into multi-column grids.

## Design System

- **Primary colour:** Blue accent
- **Background:** White
- **Text:** Dark grey / near black
- **Style:** Clean, minimal, card-based layout

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone <your-repository-link>
   ```
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or right-click it and choose **Open with Live Server**.

No installation or build step is required.

## Deployment

The site is deployed with GitHub Pages:

1. Push the project to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, select the `main` branch and the root folder.
4. Save, and the live link will appear after a minute or two.
